## Inventory method and limitations

The inventory is restricted to concrete YAML-nameable runtime traits: a class is included only when the same source file contains a companion `ClassNameInfo` deriving `TraitInfo`, `ConditionalTraitInfo`, or another TraitInfo subtype. This excludes squad state classes, state machines, fuzzy logic, helpers, wrappers, queue managers, update rules, and `*Info` metadata rows. YAML enablement is evidenced by exact trait keys in the repository's mod YAML trees.
